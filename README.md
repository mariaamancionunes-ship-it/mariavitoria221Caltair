# 🦅 Projeto Corinthians - Página com Vídeo e Interatividade

Este é um projeto de uma página web dedicada ao **Sport Club Corinthians Paulista**. O objetivo principal é criar uma interface limpa, moderna e responsiva que centraliza um conteúdo em vídeo do YouTube, além de oferecer elementos visuais e interativos que celebram a história e a paixão do clube.

---

## 📌 Objetivo do Projeto

Desenvolver uma landing page focada na experiência do usuário (UX), aplicando conceitos consolidados de desenvolvimento front-end. O projeto busca unir um design minimalista, que destaca a identidade visual do Corinthians (preto e branco), com uma estrutura de código organizada, semântica e totalmente adaptável a dispositivos móveis.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as três tecnologias pilares da web moderna:

- **HTML5:** Estruturação semântica da página e incorporação segura de mídias externas através de `<iframe>`.
- **CSS3:** Estilização baseada em propriedades modernas como **Flexbox** para centralização perfeita de elementos, `aspect-ratio` para responsividade e variáveis CSS para paleta de cores.
- **JavaScript (ES6):** Camada de interatividade do usuário, manipulação do DOM e lógica de componentes na página.

---

## ⚙️ Funcionalidades

- **Player de Vídeo Integrado:** Incorporação otimizada de vídeos do YouTube com suporte a tela cheia e carregamento assíncrono seguro.
- **Design 100% Responsivo:** A interface se adapta automaticamente a qualquer tamanho de tela (smartphones, tablets e desktops) sem distorcer o vídeo ou os textos.
- **Identidade Visual Personalizada:** Paleta de cores inspirada no "Timão", utilizando tons de preto, branco, cinza-claro e sombras suaves para profundidade visual.
- **Interatividade com JavaScript:** Recursos dinâmicos implementados via script (ex: contador de interações, alternador de modo noturno ou animações de entrada).
